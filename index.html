◈ ทางเข้าระบบสำหรับผู้มีสิทธิ์

เข้าสู่เว็บแอป

ระบบหลักทำงานบน Google Apps Script และดึงข้อมูลเวรจาก Google Sheet ที่ได้รับสิทธิ์ ไม่เก็บรายชื่อกำลังพลไว้บน GitHub Pages

ลิงก์ถูกจำไว้เฉพาะในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ได้ส่งไปที่ GitHub
เพื่อความปลอดภัยของข้อมูลกำลังพลและตารางเวร โปรดใช้บัญชี Google ที่ได้รับสิทธิ์และอย่าเผยแพร่ลิงก์ที่เปิดอ่าน/แก้ไขข้อมูลได้โดยไม่ต้องลงชื่อเข้าใช้
หน้า GitHub Pages นี้เป็นเพียงทางเข้า — การจัดเวรและการ Export Word ยังทำงานผ่าน Apps Script เดิม
