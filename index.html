เข้าสู่ระบบจัดเวรออนไลน์

ระบบจัดเวรจริงเชื่อมต่อฐานข้อมูลกลางบน Google Sheet ผ่าน Google Apps Script ของหน่วยงาน ข้อมูลเวรไม่ถูกเผยแพร่ผ่าน GitHub Pages

ฐานข้อมูลกลางGoogle Sheet ของหน่วยงาน
Dashboardปฏิทินเวรและเวรตู้สายตรวจตำบล
ข้อมูลกำลังพลนามเรียกขานและรถประจำชุด
คำสั่งราชการExport Word ผ่านเว็บแอปหลัก
กำลังตรวจการตั้งค่า…
เปิดระบบจัดเวรที่เชื่อมฐานข้อมูล
ยังไม่ได้ตั้งลิงก์เว็บแอป

ผู้ดูแลเปิดไฟล์ config.js ใน GitHub แล้วใส่ URL ที่ลงท้ายด้วย /exec ลงในช่อง webAppUrl และกด Commit changes หลังจากนั้นทุกเครื่องจะเข้าเว็บแอปเดียวกันได้โดยไม่ต้องพิมพ์ URL ซ้ำ

ไม่ต้องกรอก Google Sheet ID หรือรหัสผ่านไว้บน GitHub

กรุณาใช้บัญชี Google ที่หน่วยงานอนุญาตเข้าถึงระบบ และตั้งค่า Apps Script ให้จำกัดสิทธิ์ผู้ใช้งาน เพราะข้อมูลกำลังพลและเวรปฏิบัติงานเป็นข้อมูลภายใน
